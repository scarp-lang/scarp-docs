## इस संस्करण में क्या नया है?

| सुविधा | असली व्यवहार | सीमा |
| --- | --- | --- |
| Symbol definitions | `scarp inspect symbols --json FILE.srp` declarations और locations देता है | सिर्फ़ static inspection; LSP server नहीं |
| Cross-file references | `scarp inspect references --json FILE.srp` bindings, functions और imports के उपयोग दिखाता है | IDs एक snapshot तक सीमित; rename या incremental cache नहीं |
| Project inspection | दोनों symbol commands स्पष्ट `Scarp.project` directory स्वीकार करते हैं | वही manifest और सुरक्षित module loading नियम |
| `rms` गणना | `rms(vector) -> float` सुरक्षित scaled arithmetic से root mean square निकालता है | खाली vector पर E0034; finite values जरूरी |
| C11 परीक्षण | प्रयोगात्मक Rust embedding API के native/differential tests और मजबूत हुए | नया native executable compiler command नहीं आया |

## असली release examples चलाएँ

पूरा source और import module [टैग किए हुए examples](https://github.com/scarp-lang/scarp/tree/v0.0.6-alpha.1/examples) में हैं। **Repository checkout या extracted package के root folder** से, जहाँ `examples/` directory है, ये commands चलाएँ:

~~~sh
scarp version
scarp verify examples/symbol_navigation.srp
scarp inspect symbols --json examples/symbol_navigation.srp
scarp inspect references --json examples/symbol_navigation.srp
scarp exec examples/symbol_navigation.srp
scarp exec examples/root_mean_square.srp
~~~

[प्रकाशित symbol_navigation.srp](https://github.com/scarp-lang/scarp/blob/v0.0.6-alpha.1/examples/symbol_navigation.srp) एक असली multi-file program है:

~~~scarp
import "modules/navigation_values.srp" as library;

bind base = library.offset;
pure funcra twice(value: integer = library.offset) -> integer
    needs value >= 0;
    ensures result == value * 2;
{
    return value * 2;
}

var total = 0;
repeat 3 as step {
    bind base = twice(value: library.adjust(n: base + step));
    total += base;
}
print(total);
~~~

इसका ठीक-ठीक stdout:

~~~text
30
~~~

Static inspection `print` execute किए बिना JSON देती है। Symbols के लिए `kind: "scarp.symbols"`, references के लिए `kind: "scarp.references"`; दोनों में `schema_version: 1` है। गलत source graph से सफल inventory नहीं मिलती।

## `rms` उदाहरण

प्रकाशित [root_mean_square.srp](https://github.com/scarp-lang/scarp/blob/v0.0.6-alpha.1/examples/root_mean_square.srp) का पूरा source:

~~~scarp
// RMS measures signal magnitude without forming an overflowing norm.
bind signal = [3.0, 4.0];
print(rms(signal) > 3.5, rms(signal) < 3.6);
print(rms([2.0, -2.0]));
print(rms(window([99.0, 3.0, 4.0, 99.0], 1, 2)) == rms(signal));
print(rms([1e308, -1e308]) == 1e308);
print(rms([0.0, -0.0]));
~~~

सटीक stdout:

~~~text
true true
2.0
true
true
0.0
~~~

इसमें finite vector, window, बहुत बड़े अंक और शून्य का उदाहरण है। अधिक जानकारी [RMS गणना](/hi/language/rms-alpha6) में है।

## संस्करण सीमाएँ

`scarp inspect symbols`, `scarp inspect references` और `rms` पहली बार **v0.0.6-alpha.1** में प्रकाशित हैं; alpha.5 में नहीं। `exec` interpreter चलाता है जबकि `verify` तथा `inspect` सामान्य statements नहीं चलाते (सीमित compile-time constants अलग हैं)। Error JSON के लिए `--diagnostic-format=json` तथा सफल inventory JSON के लिए `--json` अलग options हैं।

यह release पूर्ण native compiler, GPU/async runtime, स्थायी ABI, package manager, LSP, rename engine, सामान्य tensors या automatic differentiation का दावा नहीं करता। अलग Playground तथा VS Code extension में integration अपने आप नहीं हुई।

**प्रमाण:** यह हिन्दी पृष्ठ अपरिवर्तनीय tag `v0.0.6-alpha.1` और commit `aa329a22cf2bf92d2c9814a26ff9c8b67a72e6e8` से जुड़ा है। Docs CI इन्हीं compiler examples को टैग किए हुए Rust CLI से जाँचने के लिए तैयार किया गया है।
