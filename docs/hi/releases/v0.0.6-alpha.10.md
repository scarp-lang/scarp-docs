## नई सुविधाएँ

- Opt-in `scarp exec --interactive` (and `run` / `launch`), `input`, `ask`, `ask_or`, `input_integer`, `input_float`, `input_bigint`, `--input-file PATH`.

- `try_read_line()` differentiates EOF and blank lines; `flush_stdout()` and `flush_stderr()` manage streams; `.stdout` and `.stderr` fixtures check output.

- Immutable `array<T, N>` and `[array: ...]` with checked bounds; expanded BigInt exact powers, gcd/lcm, radix conversion, modular operations.

- Array-bearing module inventory schema 3; Rust-only caching and Decimal foundations are not language constructs.

## प्रकाशित interactive example

[interactive/greeting.srp](https://github.com/scarp-lang/scarp/blob/44fcd0f77ccb92648cdb1fc7632495c506c87cb3/examples/interactive/greeting.srp)

## प्रकाशित array example

[fixed_arrays.srp](https://github.com/scarp-lang/scarp/blob/44fcd0f77ccb92648cdb1fc7632495c506c87cb3/examples/fixed_arrays.srp)

~~~scarp
pure funcra labels(values: array<string, 2> = [array: "नमस्ते", "Scarp"])
    -> array<string, 2> ensures result == values; {
    return values;
}

var index = 1;
bind grid = [array: [array: 1, 2], [array: 3, 4]];
bind empty = [array: <array<integer, 2>>];
print(labels()[index], grid[index][0], empty);
print(labels(), grid[0] == [array: 1, 2]);
~~~

~~~text
Scarp 3 [array: <array<integer, 2>>]
[array: "नमस्ते", "Scarp"] true
~~~

~~~sh
scarp verify examples/fixed_arrays.srp
scarp exec examples/fixed_arrays.srp
~~~

## सीमाएँ

Arrays immutable हैं। Prompt के लिए `--interactive` स्पष्ट देना होगा। `integer` signed i64 है और `bigint` अलग type है। Modular exponentiation variable-time है। Normal filesystem IO, native `scarp compile`, registry और stable ABI अभी नहीं हैं।
