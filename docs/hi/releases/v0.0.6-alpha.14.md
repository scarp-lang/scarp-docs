## नई सुविधाएँ और सीमाएँ

- **Nested destructuring diagnostics:** tuple, array और record patterns में missing या duplicate commas और closing delimiters अब अधिक स्पष्ट त्रुटि देते हैं। Pattern guards और refutable nested patterns अभी समर्थित नहीं।
- **Rust editor cache:** `EditorCompilationCache::set_limits` से live cache की पाँच logical quotas बदल सकती हैं; पहले से जारी programs और snapshots वैध रहते हैं।
- **Checked Linux ELF64 kernel:** Rust API `emit_elf64_checked_integer_kernel` सीमित integer bindings में checked operators, failure status और UTF-8 operator span लौटाता है।
- **Unchanged:** Scarp CLI, source syntax और JSON schemas में breaking परिवर्तन नहीं; Windows, Linux और macOS CLI interpreter पर आधारित हैं। सामान्य `scarp compile` command नहीं है।

## अपरिवर्तित tagged source और output

ये दोनों program/output जोड़े exact published compiler tag से कॉपी किए गए हैं। पहले में nested variant/record pattern binding, दूसरे में persistent map के ordered snapshots दिखते हैं। Rust host APIs को इन Scarp programs से जाँचा नहीं जाता।

### `examples/structured_pattern_coverage.srp`

[Source](https://github.com/scarp-lang/scarp/blob/43627b74af5fccccc5e233e98207413983ebafc1/examples/structured_pattern_coverage.srp) · [stdout](https://github.com/scarp-lang/scarp/blob/43627b74af5fccccc5e233e98207413983ebafc1/examples/structured_pattern_coverage.stdout)

~~~scarp
// Nested record and tuple patterns must bind exactly once per selected arm.
record Point { x: integer, y: integer }
variant Event { Move(record Point), Idle }

bind event = new Event::Move(new Point { x: 12, y: 30 });
match on event {
    case Move({x: horizontal, y: vertical}) {
        print(horizontal);
        print(vertical);
    }
    case Idle { print(0); }
}

bind pair = (4, 9);
bind (first, second) = pair;
print(first + second);
~~~

~~~text
12
30
13
~~~

### `examples/map_string_projection_snapshots.srp`

[Source](https://github.com/scarp-lang/scarp/blob/43627b74af5fccccc5e233e98207413983ebafc1/examples/map_string_projection_snapshots.srp) · [stdout](https://github.com/scarp-lang/scarp/blob/43627b74af5fccccc5e233e98207413983ebafc1/examples/map_string_projection_snapshots.stdout)

~~~scarp
// Deterministic map projections remain paired after persistent updates.
bind original = [map: "z": 9, "a": 1, "m": 5];
bind inserted = map_set(original, "b", 2);
bind replaced = map_set(inserted, "m", 50);
bind removed = map_remove(replaced, "z");

print(map_keys(original));
print(map_values(original));
print(map_keys(inserted));
print(map_values(inserted));
print(map_keys(replaced));
print(map_values(replaced));
print(map_keys(removed));
print(map_values(removed));
print(map_keys(original));
print(map_values(original));
~~~

~~~text
[list: "a", "m", "z"]
[list: 1, 5, 9]
[list: "a", "b", "m", "z"]
[list: 1, 2, 5, 9]
[list: "a", "b", "m", "z"]
[list: 1, 2, 50, 9]
[list: "a", "b", "m"]
[list: 1, 2, 50]
[list: "a", "m", "z"]
[list: 1, 5, 9]
~~~

Scarp Docs के root से alpha.14 binary पर चलाएँ:

scarp exec conformance/alpha14/structured_pattern_coverage.srp
scarp verify conformance/alpha14/map_string_projection_snapshots.srp
scarp exec conformance/alpha14/map_string_projection_snapshots.srp
~~~

`verify` static check है और `exec` interpreter में चलाता है। पुराने पाठ अपने अलग pinned release के लिए हैं।
