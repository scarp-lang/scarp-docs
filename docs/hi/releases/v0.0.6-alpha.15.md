## प्रकाशित बदलाव

- **CLI निरीक्षण:** `scarp inspect tokens` और `scarp inspect ast` तथा legacy `scarp tokens` अब नियमित UTF-8 files को अधिकतम **1 MiB (1,048,576 bytes)** तक स्वीकारते हैं। बड़ी files lexer से पहले reject होंगी।
- **String comparison:** समान UTF-8 byte length वाले strings की `==` और `!=` तुलना पर हर शुरू हुए **64 bytes** के लिए एक step लगता है। Runtime और constant evaluation दोनों पर लागू; tight budgets पहले समाप्त हो सकते हैं।
- **Cache सुरक्षा:** loader की वास्तविक revisions, caller द्वारा दी revisions से मेल खाने पर ही semantic cache reuse होता है। Rust host को `RevisionMismatch` error संभालना चाहिए।
- **Checked ELF64 shifts:** सीमित Rust object API में `<<`, `>>`, `>>>` का checked समर्थन है। Count **0–63** से बाहर हो तो status **3** (`CHECKED_KERNEL_INVALID_SHIFT`) और UTF-8 byte span मिलता है।

**सीमा:** `scarp exec` interpreter से चलता है। कोई सामान्य native compiler CLI नहीं है; ELF64 API केवल restricted Rust hosts के लिए है।

## Interpreter उदाहरण

यह सामान्य string comparison दिखाता है, विशेष step limit का प्रमाण नहीं। Code को `hello.srp` में save करें।

~~~scarp
bind left = "नमस्ते";
bind right = "नमस्ते";
print(left == right);
print(left != right);
~~~

~~~text
true
false
~~~

~~~sh
scarp version
scarp verify hello.srp
scarp exec hello.srp
~~~
