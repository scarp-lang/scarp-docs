# Scarp v0.0.6-alpha.17 — प्रकाशित प्री-रिलीज़

यह experimental interpreter **21 नवंबर 2026 को 03:44:23 UTC** पर प्रकाशित हुआ। इसे stable भाषा संस्करण नहीं समझना चाहिए।

[Official published release](https://github.com/scarp-lang/scarp/releases/tag/v0.0.6-alpha.17) · [Immutable compiler source](https://github.com/scarp-lang/scarp/tree/7831a37939965f557ce746e1d86bf82d3d629f74)

## इस रिलीज़ में नया क्या है?

- Pure `array_len(values)` immutable fixed array के तत्वों की संख्या देता है।
- `array_get_or(values, index, fallback)` गलत index पर सही type वाला fallback देता है। **Index सही होने पर भी fallback का मूल्यांकन एक बार होता है**। सामान्य `values[index]` में E0063 की सीमा-जाँच बनी रहती है।
- Interactive mode में `input_boolean(prompt)` केवल lowercase `true` और `false` स्वीकार करता है। गलत अक्षरों पर **E0084** और नई पंक्ति से पहले input समाप्त होने पर **E0055** मिलता है।
- Nested fixed-array type में गलत length का diagnostic अब सटीक source span के साथ आता है।
- यह सामान्य native compiler या stable package manager नहीं है।

## Fixed array पर वास्तविक उदाहरण

~~~scarp
bind readings = [array: 10, 20, 30];
var total = 0;
repeat array_len(readings) as index {
    total += readings[index];
}
print("Total:", total);
print("Missing reading:", array_get_or(readings, 3, 0));
print("Empty length:", array_len([array: <integer>]));
~~~

Compiler के प्रकाशित tag में शामिल अपेक्षित output:

~~~text
Total: 60
Missing reading: 0
Empty length: 0
~~~



## Boolean prompt को दोहराकर चलाएँ

~~~sh
scarp exec --interactive --input-file examples/interactive/boolean_prompt.stdin examples/interactive/boolean_prompt.srp
~~~

~~~scarp
// Run with scarp exec --interactive examples/interactive/boolean_prompt.srp.
repeat 2 as attempt {
    bind confirmed: boolean = input_boolean("Continue (true/false)? ");
    if confirmed {
        print("Continuing");
    } else {
        print("Stopped");
        break;
    }
}
~~~

इनपुट फ़ाइल में ठीक दो पंक्तियाँ हैं:

~~~text
true
false
~~~

प्रकाशित stdout snapshot में prompts और परिणाम साथ आते हैं:

~~~text
Continue (true/false)? Continue (true/false)? Continuing
Stopped
~~~


ऊपर के प्रोग्राम और output मूल [tagged compiler examples](https://github.com/scarp-lang/scarp/tree/7831a37939965f557ce746e1d86bf82d3d629f74/examples) से बिना बदलाव लिए गए हैं। पुराने compiler में इन्हें चलाने की गारंटी नहीं है। `scarp version` अवश्य जाँचें।
