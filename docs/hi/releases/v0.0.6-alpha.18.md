## प्रकाशित बदलाव

1. **एक ही कमांड से चलाएँ:** `scarp exec` बिना file path के वर्तमान directory में मान्य `scarp.project` या पुराने `Scarp.project` का entrypoint चुनता है। Manifest न मिले तो पहले `src/main.srp`, उसके बाद `main.srp` चुनता है। खराब manifest पर error मिलता है; दूसरी file स्वतः नहीं चलाई जाती।
2. **Input/Output:** `exec` में सीमित interactive prompts और typed input की आवश्यकता पड़ने पर स्वतः सुविधा मिलती है। पुराने `run` में prompt के लिए explicit opt-in जारी है।
3. **Immutable fixed array:** `array_set(values, index, replacement)` एक नया `array<T, N>` देता है; पुरानी aliases नहीं बदलतीं। गलत index पर E0063 तथा नई backing के cumulative budget पर E0064 आता है। `values[index] = x` अभी समर्थित नहीं है।
4. **Lifetime:** खाली numeric windows पुराने बड़े backing buffer से अलग रखी जाती हैं। Nonempty windows अभी भी immutable storage साझा करती हैं। यह cycle collector या पूरी RAM की सीमा नहीं है।
5. **विश्वसनीयता:** Prompt flush के interruption को सीमित work budget के भीतर दोबारा सँभाला जाता है और JSON-inspection regression tests बढ़े हैं।

## कमांड उदाहरण

~~~sh
scarp version
scarp exec
scarp exec calculator.srp
scarp exec src/calculator.srp
scarp verify src/main.srp
~~~

ये कमांड interpreter के लिए हैं, native executable बनाने के लिए नहीं। `scarp compile` जैसा सामान्य native CLI अभी उपलब्ध नहीं है। Source से build करने के लिए Rust 1.74 या नया toolchain चाहिए।


## Immutable array update का उदाहरण

~~~scarp
pure funcra replace_last(values: array<integer, 3>) -> array<integer, 3> {
    return array_set(values, 2, 100);
}

bind original = [array: 4, 8, 12];
bind updated = array_set(original, 1, 99);
print(original[1], updated[1], array_len(updated));

bind nested = [array: [array: "one"], [array: "two"]];
bind localized = array_set(nested, 0, [array: "नमस्ते"]);
print(nested[0][0], localized[0][0]);
print(replace_last(updated)[2]);
~~~

Compiler tag में सुरक्षित output:

~~~text
8 99 3
one नमस्ते
100
~~~


## Numerical window और Lifetime का उदाहरण

~~~scarp
// Lifetime preserves value snapshots without explicit memory management.
bind data = [1.0, 2.0, 3.0];
bind tail = window(data, 1, 2);
bind empty = window(data, 2, 0);
print(len(empty), tail);

bind numbers: integers = [integer: 7, 8, 9];
bind empty_numbers = ints_window(numbers, 2, 0);
print(ints_len(empty_numbers), ints_window(numbers, 1, 2));
~~~

प्रकाशित compiler tag का output:

~~~text
0 [2.0, 3.0]
0 [integer: 8, 9]
~~~
