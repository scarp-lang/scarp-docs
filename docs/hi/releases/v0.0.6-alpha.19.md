# Scarp v0.0.6-alpha.19 — पुराना प्रकाशित प्री-रिलीज़

23 नवंबर 2026 को प्रकाशित। नए installation के लिए [आधिकारिक Downloads](https://scarp-lang.github.io/downloads/) और [वर्तमान documentation](/hi/guide/current) प्रयोग करें।

इस release में checked Rust callable handles, named arguments, defaults, signature/effect आधारित slots, exported module selection और cumulative execution receipts आए। ये Rust host embedding की सुविधाएँ हैं, source भाषा की first-class function values नहीं।
