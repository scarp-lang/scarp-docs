## इस संस्करण में क्या आया?

ये सुविधाएँ **Rust embedding library की वैकल्पिक APIs** हैं। Scarp भाषा का नया syntax या नया CLI command **नहीं** आया है।

| सुविधा | व्यवहार और सीमाएँ |
| --- | --- |
| Module invalidation | Dependency graph से सुरक्षित तरीके से प्रभावित files की योजना बनती है; वर्तमान source की दोबारा जाँच जरूरी है |
| Semantic cache | Bytes, imports, पहचान, compiler limits, labels और revisions पूरे मेल खाने पर सफल whole-graph resolution दुबारा उपयोग होता है; त्रुटियों को पुरानी सफलता से नहीं छिपाया जाता |
| Token और syntax caches | सफल tokens और AST दोबारा उपयोग होते हैं तथा source positions सही जगह बदले जाते हैं; import, syntax, type और resource जाँच जारी रहती है |
| Edit preflight और eviction | पूरी edit list की सीमाएँ जाँचकर प्रभावित cache entries हटती हैं; अनजान पहचान होने पर सुरक्षित पूर्ण invalidation होता है, पुरानी लौटाई objects का secure erasure नहीं |
| C11 scalar emitter | पहले से सीमित Rust API की internal preflight बेहतर हुई; कोई नया native CLI compiler नहीं |

सही Rust API के लिए [प्रकाशित development contracts](https://github.com/scarp-lang/scarp/tree/398b8ff705154a02423fe458ce3a427401e81e31/docs/development) देखें: `incremental-invalidation.md`, `semantic-cache.md`, `token-cache.md`, `syntax-cache.md`, `cache-edit-planning.md` और `cache-eviction.md`। Binary archives में अलग से compiled Rust library **नहीं** दी जाती।

## पहले से उपलब्ध CLI

Archive निकालने के बाद `examples/` वाले directory में ये पहले से उपलब्ध commands चलाए जा सकते हैं:

~~~sh
scarp version
scarp guide
scarp verify examples/hello.srp
scarp exec examples/hello.srp
~~~

भाषा और असली runnable examples के लिए [alpha.6 symbols/CLI](/hi/tooling/cli-alpha6) और [RMS पाठ](/hi/language/rms-alpha6) पढ़ें। पुराने conformance examples को जानबूझकर **v0.0.6-alpha.1** पर रखा गया है; नई Rust caching APIs उन्हें अपने आप नए tag पर सत्यापित नहीं करतीं।

## अभी क्या उपलब्ध नहीं है?

`scarp compile`, `scarp build`, सामान्य native object writer, LSP server, file watcher, package registry और GPU/async runtime शामिल **नहीं** हैं। Cache quotas logical retention limits हैं, कुल heap memory की गारंटी या हर मशीन पर speedup नहीं। [Feature status](/hi/reference/status) और [सही CLI Command Finder](/hi/tooling/command-finder) देखें।
