## मुख्य बदलाव

- Exact decimal literal में lowercase `d` suffix उपलब्ध है। `0.1d + 0.2d` का परिणाम `0.3` है। बिना suffix वाले literals binary64 float ही हैं।
- Mutable `var` tuple में constant index पर member बदल सकते हैं। पुरानी aliases का value नहीं बदलता। Compatible numeric tuples की lexicographic ordering भी उपलब्ध है।
- नया project `scarp.project` बनाता है। पुरानी `Scarp.project` file अभी पढ़ी जा सकती है।
- Experimental Rust host native-object API Linux x86-64 System V target पर एक से छह integer parameters वाले pure functions को स्वीकार करती है। यह सामान्य native compilation CLI नहीं है।
- Host quota अब composite के अंदर की strings के logical UTF-8 bytes भी गिनता है; shared string की हर occurrence गिनी जाती है।

## भाषा और सीमाएँ

उदाहरणों और सीमाओं के लिए [वर्तमान भाषा संदर्भ](/hi/reference/current) पढ़ें। मूल compiler परीक्षण: [decimal literals](https://github.com/scarp-lang/scarp/blob/b1a9347f93540fdf95b0ddecba4adc55a3b4bb98/tests/decimal_literals.rs), [tuple updates](https://github.com/scarp-lang/scarp/blob/b1a9347f93540fdf95b0ddecba4adc55a3b4bb98/tests/tuple_index_updates.rs), [tuple ordering](https://github.com/scarp-lang/scarp/blob/b1a9347f93540fdf95b0ddecba4adc55a3b4bb98/tests/tuples.rs)।

CLI अभी interpreter है। `scarp exec FILE.srp` या project directory में `scarp exec` चलाएँ। गलत project manifest पर error मिलता है; दूसरी file स्वतः नहीं चलती।

## Rust embedding

नई native API में `scarp_checked_integer_function` symbol है, जिसका signature object के अनुसार निश्चित है। Arithmetic failure पर status और source-span index मिलता है। Loops, calls, contracts, defaults और heap-backed values इस subset में नहीं हैं। Host ledger interpreter usage और argument admission गिनता है, पूरे process की RAM नहीं। [Native ELF64 विवरण](https://github.com/scarp-lang/scarp/blob/b1a9347f93540fdf95b0ddecba4adc55a3b4bb98/docs/native-elf64.md) और [host quota contract](https://github.com/scarp-lang/scarp/blob/b1a9347f93540fdf95b0ddecba4adc55a3b4bb98/docs/development/cumulative-host-quotas-alpha19.md) देखें।
