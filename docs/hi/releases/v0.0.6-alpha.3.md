## चार नए numerical functions

| फ़ंक्शन | परिणाम का प्रकार | क्या करता है |
| --- | --- | --- |
| `topk(scores, count)` | `integers` | स्कोर घटते क्रम में मूल zero-based index; बराबरी पर पहले index को प्राथमिकता |
| `topk_values(scores, count)` | `vector` | उसी क्रम में मूल स्कोर लौटाता है |
| `softmax_temp(scores, temperature)` | `vector` | Temperature के अनुसार finite probability |
| `logsoftmax_temp(scores, temperature)` | `vector` | Finite log probability, या स्पष्ट diagnostic |

Top-K में `count = 0` मान्य है, खाली vector पर भी। गलत count से E0033 diagnostic मिलता है। Signed zero की बराबरी पर मूल index से क्रम तय होता है। Temperature शून्य से अधिक और finite float होनी चाहिए। `1.0` पर परिणाम पुराने softmax जैसा होता है। Memory और work की सीमाएँ हैं; बहुत छोटी temperature से probability शून्य हो सकती है, लेकिन अमान्य log probability स्वीकार नहीं की जाती।

~~~scarp
bind scores = [1.0, 5.0, 5.0, -2.0, 3.0];
print(topk(scores, 3));                // [integer: 1, 2, 4]
print(topk_values(scores, 3));         // [5.0, 5.0, 3.0]
print(topk(softmax_temp(scores, 0.5), 2)); // [integer: 1, 2]
~~~

प्रकाशित टैग पर [topk_scores.srp](https://github.com/scarp-lang/scarp/blob/ceff07d9014f466974e0c9e02fc5d23573f55777/examples/topk_scores.srp), [temperature_softmax.srp](https://github.com/scarp-lang/scarp/blob/ceff07d9014f466974e0c9e02fc5d23573f55777/examples/temperature_softmax.srp) और उनकी `.stdout` files उपलब्ध हैं। सटीक त्रुटियाँ, गणना और resource limits के लिए [Top-K reference](https://github.com/scarp-lang/scarp/blob/ceff07d9014f466974e0c9e02fc5d23573f55777/docs/topk-selection.md) और [temperature reference](https://github.com/scarp-lang/scarp/blob/ceff07d9014f466974e0c9e02fc5d23573f55777/docs/temperature-softmax.md) पढ़ें।

## Compiler के अंदर हुए बदलाव

Private scalar IR, definite-initialization जाँच और interpreter के साथ test-only differential जाँच जोड़ी गई। यह सामान्य native compiler **नहीं** है। `scarp compile`/`scarp build`, LSP, GPU runtime, tensor engine, package manager, agent framework या sampling API नहीं आई। इन functions के अलावा नया CLI subcommand या syntax नहीं आया। पिछली [alpha.2 रिलीज़](/hi/releases/v0.0.6-alpha.2) में Rust caching APIs हैं।
