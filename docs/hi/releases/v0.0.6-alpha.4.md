## इस रिलीज़ की सुविधाएँ

- `sample_area(x, y)` trapezoid विधि से क्षेत्रफल, `sample_cumulative_area(x, y)` प्रत्येक चरण का संचयी क्षेत्रफल और `sample_slopes(x, y)` लगातार नमूनों की ढलान निकालता है। Finite, बराबर आकार के vectors और बढ़ते x-coordinates चाहिए।
- `cosine_similarity(left, right)` दो समान लंबाई वाले nonzero finite vectors की similarity निकालता है; scaled compensated गणना उपयोग होती है।
- `scarp::native_object::emit_elf64_integer_kernel` एक **सीमित Rust API** है जो restricted integer initializer से x86-64 ELF64 relocatable object देता है। यह सामान्य native compiler या `scarp compile` नहीं।

Interpreter CLI और keywords नहीं बदले। Top-P, Pearson correlation, GPU, tensors, सामान्य native executables, LSP और package registry alpha.4 में **उपलब्ध नहीं हैं**।
