## नई प्रकाशित सुविधाएँ

- **निश्चित Top-P चयन:** `top_p(probabilities, mass)` probability के घटते क्रम में मूल zero-based indices लौटाता है। `top_p_values(probabilities, mass)` उन्हीं के values लौटाता है। यह **random sampling नहीं** करता।
- **Pearson correlation:** `pearson_correlation(left, right)` समान लंबाई के दो finite, nonconstant vectors का mean-centered संबंध निकालता है। `cosine_similarity` से अंतर यह है कि दोनों axes को अलग-अलग center करता है।
- **सीमित native object API:** Rust का `scarp::native_object::emit_elf64_integer_kernel(source)` अब पिछले integer bindings को पढ़ने वाले कुछ क्रमबद्ध integer bindings स्वीकार करता है। Output **x86-64 ELF64 relocatable object** है; standalone executable नहीं।

शर्तें और सीमाएँ [Top-P मार्गदर्शिका](/hi/language/nucleus-selection-alpha5) और [Pearson correlation पाठ](/hi/language/pearson-correlation-alpha5) में देखें।

## प्रकाशित tag से पूरे runnable उदाहरण

नीचे दोनों Scarp source और उनके अपेक्षित stdout को प्रकाशित compiler tag से **बिना बदलाव** लिया गया है। सही तुलना के लिए प्रकाशित alpha.5 interpreter से `.srp` को `scarp exec` द्वारा चलाएँ।

### `nucleus_selection`

~~~scarp
// Deterministic nucleus selection: rank the smallest probability prefix
// covering the specified cumulative mass without random sampling.
bind probabilities = [0.5, 0.25, 0.25];
print(top_p(probabilities, 0.75));
print(top_p_values(probabilities, 0.75));
print(top_p(probabilities, 1.0));

bind logits = [1.0, 4.0, 4.0, 2.0];
print(top_p(softmax_temp(logits, 0.5), 0.9));
~~~

~~~text
[integer: 0, 1]
[0.5, 0.25]
[integer: 0, 1, 2]
[integer: 1, 2]
~~~

### `pearson_correlation`

~~~scarp
// Pearson correlation: centered scientific statistics, not cosine similarity.
bind measurements = [1.0, 2.0, 3.0];
print(pearson_correlation(measurements, [10.0, 20.0, 30.0]));
print(pearson_correlation(measurements, [30.0, 20.0, 10.0]));
print(pearson_correlation([-1.0, 0.0, 1.0], [1.0, -2.0, 1.0]));
~~~

~~~text
1.0
-1.0
0.0
~~~

## अभी क्या उपलब्ध नहीं है?

पुराने interpreter CLI commands बने हुए हैं। सामान्य `scarp compile`, native executable linker, GPU, tensors, autodiff, random sampler, पूर्ण LSP और package registry **इस release में नहीं** आए हैं। Rust के `numeric::Builtin` enum पर exhaustive match लिखने वाले developers को नए variants संभालने होंगे।
