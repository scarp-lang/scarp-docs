## तीन नई प्रकाशित सुविधाएँ

- **सीमित program input:** `read_line() -> string` explicit UTF-8 line पढ़ता है। `exec`, `run` और project `launch` में **redirected stdin** चलता है; interactive terminal prompt शामिल नहीं है। [पूरी जानकारी](/hi/language/program-input-alpha6)।
- **साफ़ scalar/text conversion:** `integer_to_text`, `float_to_text`, `text_to_integer`, `text_to_float`, `text_trim`, `text_replace`। गलत input पर त्रुटि मिलती है; automatic conversion नहीं। [संदर्भ](/hi/language/text-foundations-alpha6)।
- **Immutable अलग-अलग प्रकार वाले tuples:** `(42, "नमस्ते")`, singleton `(42,)`, `tuple<integer, string>`, literal index `pair[0]` और structural equality। `var` में पूरी tuple value समान exact type से बदली जा सकती है। [Tuples सीखें](/hi/language/tuples-alpha6)।

## Tagged compiler का exact source और output

आधिकारिक उदाहरण **दो source files** का है, केवल एक file का नहीं। यह [`examples/modules/input_record.srp`](https://github.com/scarp-lang/scarp/blob/cdf6a3924ec2a36c7beca5a9aec4f01a0bce515e/examples/modules/input_record.srp) import करता है; पहली line का नंबर parse करता है, दूसरी में underscores बदलता है और tuple लौटाता है। [Source](https://github.com/scarp-lang/scarp/blob/cdf6a3924ec2a36c7beca5a9aec4f01a0bce515e/examples/core_input_tuple.srp), [stdin](https://github.com/scarp-lang/scarp/blob/cdf6a3924ec2a36c7beca5a9aec4f01a0bce515e/examples/core_input_tuple.stdin) और [stdout](https://github.com/scarp-lang/scarp/blob/cdf6a3924ec2a36c7beca5a9aec4f01a0bce515e/examples/core_input_tuple.stdout) प्रकाशित tag से हैं। Input fixture में दो CRLF-terminated lines हैं: ` 42\r\n नमस्ते_🌍\r\n`। Source के साथ उसी relative path में module रखकर **v0.0.6-alpha.6** compiler चलाएँ:

~~~scarp
// alpha.6 candidate: redirected UTF-8 input, text conversion and imported tuples.
import "modules/input_record.srp" as records;
bind entry: tuple<integer, string> = records.read();
print(entry);
print(records.describe(entry));
~~~

Tag के interpreter से exact stdout:

~~~text
(42, "नमस्ते 🌍")
42: नमस्ते 🌍
~~~

Unix-like shell में tagged checkout से चलाने का उदाहरण:

~~~sh
scarp exec examples/core_input_tuple.srp < examples/core_input_tuple.stdin
~~~

यह interpreter से चलता है, native executable नहीं बनाता। Static `verify` या evaluating `check` को redirected input उपलब्ध मानना गलत होगा।

## सीमाएँ और compatibility

- **Input:** default 65,536 raw bytes प्रति line, 1,048,576 total और 4,096 reads। `--max-input-line-bytes`, `--max-input-bytes` और `--max-input-reads` बदल सकते हैं। CR/LF terminators भी quota में गिने जाते हैं। Terminal-connected input समर्थित नहीं।
- **Tuples:** 1–32 members, अधिकतम depth 32, 4,096 structural type nodes और default कुल 8 MiB tuple payload। `--max-tuple-bytes` आखिरी सीमा बदलता है।
- **Rust embedding:** `SourceType`, `Value::Tuple` और `ExecutionOptions.max_tuple_bytes` से कुछ host integrations बदलते हैं। Tuple function signatures वाली module inventory schema 2 उपयोग करती है।
- **उपलब्ध नहीं:** empty tuples, destructuring, dynamic indexes, element mutation, BigInt, interactive prompts, सामान्य `scarp compile`, native executables, GPU या stable ABI। सीमित C11/ELF64 Rust APIs input/tuples नहीं संभालतीं।
