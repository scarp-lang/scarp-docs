## दो नई प्रकाशित language सुविधाएँ

- **Typed conditional expressions:** `if`/`elif`/`else` अब value लौटा सकते हैं। Conditions boolean होती हैं, हर branch का exact result type समान होता है, अंतिम `else` ज़रूरी है, और runtime में केवल चुनी हुई branch execute होती है। [सीखें](/hi/language/conditional-expressions-alpha7)।
- **Unicode scalar escapes:** quoted string में `\u{HEX}` लिखा जा सकता है। एक से छह ASCII hex digits मान्य हैं। Invalid escape, surrogate और U+10FFFF से बड़ी value पर `E0003` मिलता है। [सीखें](/hi/language/unicode-escapes-alpha7)।

**सीमाएँ:** नहीं चुनी गई branches भी statically typecheck होती हैं। Conditional expressions को module constants या experimental C11/ELF64 native emitters में उपयोग नहीं कर सकते। यह release BigInt, native `scarp compile`, interactive input prompt या stable ABI नहीं देता।

## आधिकारिक source और सही output

यह पूरा उदाहरण immutable compiler tag के [`examples/conditional_unicode.srp`](https://github.com/scarp-lang/scarp/blob/b1c1fd232b418267d95520c69ee563ac99ecae30/examples/conditional_unicode.srp). [stdout प्रमाण](https://github.com/scarp-lang/scarp/blob/b1c1fd232b418267d95520c69ee563ac99ecae30/examples/conditional_unicode.stdout):

~~~scarp
bind score = 73;
bind label = if score >= 90 {
    "\u{1F44B}"
} elif score >= 60 {
    "\u{0928}\u{092E}\u{0938}\u{094D}\u{0924}\u{0947} \u{1F44B}"
} else {
    text_repeat("unreached", -1)
};
print(label, if true { 7 } else { 1 / 0 });
~~~

~~~text
नमस्ते 👋 7
~~~

~~~sh
scarp exec examples/conditional_unicode.srp
~~~

उदाहरण की `else` branch में ऐसा runtime operation है जो चुने जाने पर विफल होता। उसका न चलना lazy selection साबित करता है, static checking को छोड़ना नहीं।
