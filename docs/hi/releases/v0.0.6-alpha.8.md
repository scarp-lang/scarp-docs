## इस release में प्रकाशित project और test सुविधाएँ

- `scarp init DIRECTORY` नए folder में `scarp.project` नाम का Scarp का अपना declarative manifest बनाता है। पहले से मौजूद directory overwrite नहीं होती।
- `scarp run [DIRECTORY]` project entrypoint execute करता है और `scarp verify [DIRECTORY]` सामान्य runtime code चलाए बिना static जाँच करता है। पुराना `Scarp.project`, `scarp create`, `scarp launch` तथा file वाला `scarp exec` भी मौजूद है।
- `scarp project info [--json] [DIRECTORY]` validated metadata दिखाता है, application execute नहीं करता।
- `scarp test [DIRECTORY]` सीधे `tests/*.srp` files चलाता है। `--list` बिना चलाए सूची देता है; `--json` structured result, `--filter TEXT` filename substring के आधार पर चयन और `--require-tests` खाली suite पर failure देता है।
- Test की अपनी `.stdin` file से UTF-8 input दिया जा सकता है। `assert(boolean, "message");` गलत condition पर source-location सहित **E0065** diagnostic देता है।

ये सुविधाएँ **प्रकाशित alpha.8** की हैं; alpha.7 में इनके उपलब्ध होने का दावा नहीं है। [पूरा calculator tutorial](/hi/tutorials/calculator-alpha8) और [नए project commands](/hi/tooling/project-alpha8) पढ़ें।

## Tagged compiler से सत्यापित calculator उदाहरण

यह `examples/projects/calculator/src/main.srp` की वही source है जो `37253e7805c0ca594560700dd1deb3928458e60d` commit में प्रकाशित है। इस program का output `5` है। इसके लिए `math.srp` module भी चाहिए; [पूर्ण calculator project](/hi/tutorials/calculator-alpha8) में वह मौजूद है।

~~~scarp
import "math.srp" as math;

print(math.add(2, 3));
~~~

~~~text
5
~~~

~~~sh
scarp verify examples/projects/calculator
scarp run examples/projects/calculator
scarp test --require-tests examples/projects/calculator
~~~

ये commands **उसी tagged compiler source checkout** के root से चलाएँ, जहाँ `examples/projects/calculator` directory है; अकेली extracted binary में यह example project अपने-आप नहीं होगा। `verify` सामान्य runtime execution नहीं करता, लेकिन `run` और `test` source चलाते हैं।

## Compatibility और महत्वपूर्ण सीमाएँ

पुराना `Scarp.project`, `create`, `launch`, `exec` समर्थित रहता है। नया `assert` reserved statement है; पुराने code में इस नाम का variable या function बदलना होगा। Rust embedder में exhaustive `Statement` तथा `DiagnosticKind` matching के लिए नए `Assert`/`AssertionFailure` variants संभालें।

Test discovery nonrecursive है और अधिकतम **64** सीधे `.srp` files देखता है। खाली suite सामान्यतः सफल है; CI में `--require-tests` लें। `dependencies {}` अभी खाली reserved grammar है, package installer नहीं। कोई registry, सामान्य native `scarp compile` CLI या पुराने code की हर release में compatibility की guarantee नहीं है। Native assertion interpreter में है, experimental native backends में नहीं। मुख्य language reference [v0.0.5-alpha.1](/hi/reference/status) पर pin है; [अन्य release की सुविधा](/hi/reference/compatibility) अलग जाँचें।
