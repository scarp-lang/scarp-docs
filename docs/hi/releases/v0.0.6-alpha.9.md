**13 नवंबर 2026, 11:22:47 UTC को प्रकाशित।** यह प्रयोगात्मक prerelease है; stable भाषा या native executable compiler नहीं है। [रिलीज़ टैग](https://github.com/scarp-lang/scarp/releases/tag/v0.0.6-alpha.9) compiler source commit `0814997dc43982eb707a9a1aee72aab3a7ac8b41` पर आधारित है। [पिन किया गया source](https://github.com/scarp-lang/scarp/tree/0814997dc43982eb707a9a1aee72aab3a7ac8b41) और [प्रकाशन विवरण](https://github.com/scarp-lang/scarp/blob/0814997dc43982eb707a9a1aee72aab3a7ac8b41/docs/releases/v0.0.6-alpha.9-publication.md) देखें।

## इस रिलीज़ में नया

- **BigInt के साथ सटीक पूर्णांक:** `bigint("12345678901234567890")` बहुत बड़े signed decimal पूर्णांक को सटीक रखता है। अलग `bigint` type में गणना, तुलना, functions, modules और tuples चलते हैं। पुराना `integer` अभी signed 64-bit ही है।
- **Tests की संरचित रिपोर्ट:** `scarp test --json=v2` में fail होने वाले test के लिए `compile`, `fixture`, `runtime` चरणों के diagnostics मिलते हैं। पुराना `--json` schema version 1 ही देता है।
- **सीमित संसाधन:** BigInt में डिफ़ॉल्ट 10,000 decimal digits और cumulative 8 MiB limb budget है। ऊपरी सीमा 1,000,000 digits है, लेकिन काम और मेमोरी की अन्य सीमाएँ भी लागू रहती हैं।

[BigInt पाठ](/hi/language/bigint-alpha9), [JSON-v2 टेस्ट रिपोर्ट](/hi/tooling/test-json-v2-alpha9) और पिछले [alpha.8 calculator प्रोजेक्ट](/hi/tutorials/calculator-alpha8) से आगे सीखें। यहाँ का code केवल प्रकाशित alpha.9 के exact source पर आधारित है।

## Tagged compiler से बिल्कुल वही उदाहरण

नीचे का source और stdout प्रकाशित compiler के [मूल source](https://github.com/scarp-lang/scarp/blob/0814997dc43982eb707a9a1aee72aab3a7ac8b41/examples/bigint_arithmetic.srp) एवं [stdout fixture](https://github.com/scarp-lang/scarp/blob/0814997dc43982eb707a9a1aee72aab3a7ac8b41/examples/bigint_arithmetic.stdout) से बिना बदलाव लिया गया है:

~~~scarp
// Development BigInt milestone; unavailable in published alpha.4.
bind a: bigint = bigint("999999999999999999999999999999");
bind one = bigint_from_integer(1);
print(a + one);
print(a * bigint("123456789"));
print(-a / bigint("1000000000000000000"));
print(-a % bigint("1000000000000000000"));
print(a > one, bigint_abs(-a) == a, bigint_to_integer(one));
~~~

~~~text
1000000000000000000000000000000
123456788999999999999999999999876543211
-999999999999
-999999999999999999
true true 1
~~~

उसी alpha.9 compiler और examples वाला source checkout खोलकर ये commands चलाएँ:

~~~sh
scarp verify examples/bigint_arithmetic.srp
scarp exec examples/bigint_arithmetic.srp
~~~

`verify` केवल static जाँच करता है, जबकि `exec` interpreter से code चलाता है। यदि source बदला जाए तो पुराने stdout को नया सत्यापित output न मानें।

## Compatibility और सीमाएँ

`integer` signed i64 ही है। `bigint_from_integer` और `bigint_to_integer` के माध्यम से conversion स्पष्ट करना होगा; i64 की सीमा से बाहर conversion error है। BigInt भागफल शून्य की ओर truncate होता है, remainder का sign dividend के अनुसार रहता है। बिना conversion float/BigInt मिश्रण, BigInt bitwise संचालन, fixed-size BigInt arrays और सामान्य `scarp compile` **उपलब्ध नहीं** हैं। Rust embedding करने वालों को `ExecutionOptions` के नए fields और exhaustive type/diagnostic matches अपडेट करने पड़ सकते हैं। [विस्तृत compiler contract](https://github.com/scarp-lang/scarp/blob/0814997dc43982eb707a9a1aee72aab3a7ac8b41/docs/bigint.md) पढ़ें।

पिछली [alpha.8 release](/hi/releases/v0.0.6-alpha.8) में projects, `scarp test` और `assert` पहली बार प्रकाशित हुए थे; उसके उदाहरण ऐतिहासिक version से जुड़े रहेंगे।
