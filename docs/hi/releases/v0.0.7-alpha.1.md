## नई सुविधाएँ

- `array_concat` समान element type वाली fixed arrays जोड़ता है।
- `integer_gcd`, `integer_hcf` और `integer_lcm` दो से 1024 integers स्वीकार करते हैं।
- Vector softplus finite inputs पर stable numerical calculation करता है।
- Interpreter सीमित frame buffers reuse करता है; returned immutable values अगले calls में सुरक्षित रहती हैं।
- Rust hosts token-cache limits बदल सकते हैं; insertion-order eviction पुराने compiled snapshots को invalidate नहीं करता।
- Experimental ELF64 API 16 तक required integer arguments और counted repeats सहित सीमित native control flow देता है।
- `scarp exec` bounded input के साथ interpreter चलाता है। `scarp.project` नया manifest है; `Scarp.project` भी पढ़ा जाता है।

[Release guide](/hi/guide/alpha7-first) में उदाहरण देखें। General native function calls, executable linking और native compilation CLI शामिल नहीं हैं।
