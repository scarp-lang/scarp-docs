## नई सुविधाएँ

- `scarp native-object` pure integer functions से relocatable x86-64 ELF64 object बनाता है।
- `bounded-entry` एक source file में nonrecursive direct calls और work/stack budgets जाँचता है।
- 16 तक integer arguments: छह registers में और शेष stack में।
- Rust API tuples, records, arrays, variants, Option और Result की layout जानकारी देता है; aggregate execution अभी नहीं।
- `scarp exec` interpreter ही है। General linking, external calls, native recursion और heap-backed values उपलब्ध नहीं हैं।
