# Scarp v0.0.7-alpha.3 — प्रकाशित prerelease

27 नवंबर 2026, 12:32:43 UTC को प्रकाशित। [Release](https://github.com/scarp-lang/scarp/releases/tag/v0.0.7-alpha.3) · [Source](https://github.com/scarp-lang/scarp/tree/44a3bb0a91e67570e46ce058a3f6211f8e5db0f5).

यह पृष्ठ प्रकाशित compiler का प्रमाण सुरक्षित करता है। वर्तमान documentation baseline का परिवर्तन अलग validation के बाद होगा।

## नई सुविधाएँ

- Generic functions में bounded specialization, explicit type arguments और contextual inference उपलब्ध हैं।
- Generic Option और Result payloads में type inference और pattern matching उपलब्ध हैं।
- Native ELF64 integer entry concrete integer specializations तथा flat fixed arrays, tuples और records के private stack locals को स्वीकार करती है।
- Checked constant folding error, span और work accounting को सुरक्षित रखती है।
- String concatenation, repetition, raw और multiline literals interpreter में उपलब्ध हैं।
- Lifetime function completion पर अनुपयोगी interpreter values retire करता है; यह पूरे process की RAM सीमा नहीं है।

## सीमाएँ

`scarp exec` interpreter ही है। Native output केवल experimental relocatable x86-64 ELF64 object है, जिसे external linker चाहिए। Native aggregate components integer या Boolean हैं; general native executable compilation, external calls, recursion और heap-backed values का समर्थन नहीं माना जाना चाहिए।
