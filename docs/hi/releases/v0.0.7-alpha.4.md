## नेटिव कोड और स्टैक

- Experimental Rust API `emit_elf64_recursive_integer_entry` सीमित self/mutual recursion और अलग work, active-frame, stack limits देता है। `scarp native-object` CLI अब भी nonrecursive है।
- Private native frame में nested fixed arrays, tuples और records के अधिकतम 32 integer/Boolean leaf values रखे जा सकते हैं।
- Checked index failure का source span सुरक्षित रहता है। Public ABI अभी भी integer arguments और checked integer result तक सीमित है।
- `scarp exec` अब भी interpreter चलाता है। Native object को executable बनाने के लिए बाहरी linker चाहिए।

[Nested aggregate और recursion पाठ](/hi/guide/v007-alpha4-systems) · [Compiler native ELF64 contract](https://github.com/scarp-lang/scarp/blob/e620bdcb512fbe909b08f1b4cc625865e4cdf339/docs/native-elf64.md).

## BigInt और सही-सही गणना

- Contextual return type, inner generic call के type inference में मदद कर सकता है।
- Bounded `bigint_pow_big` और `bigint_pow_mod_big` बड़े exponent के साथ काम करते हैं; digit और work budgets लागू होते हैं।
- प्रयोगात्मक `scarp bigint` command file-backed add, sub, सीमित mul, div और div-wide देता है। परिणाम नई file में लिखता है।
- File division का quotient zero की ओर truncate होता है; remainder, dividend के sign का होता है।

[BigInt का पाठ](/hi/guide/v007-alpha4-bigint) · [Tagged compiler BigInt contract](https://github.com/scarp-lang/scarp/blob/e620bdcb512fbe909b08f1b4cc625865e4cdf339/docs/bigint.md).
