## Newly published features

Scarp alpha.12 introduces typed source records, tagged variants, nested destructuring and exhaustively checked pattern matching. `option<T>` and `result<T,E>` support checked early propagation using `?`. Immutable dynamic lists, deterministic maps and a multi-file task-board application are also released.

## Tagged record and variant example

[variant_validation.srp](https://github.com/scarp-lang/scarp/blob/a1f9c2fc1c6bc8f3e04878d30d658bb38fab441d/examples/variant_validation.srp) · [expected stdout](https://github.com/scarp-lang/scarp/blob/a1f9c2fc1c6bc8f3e04878d30d658bb38fab441d/examples/variant_validation.stdout)

~~~scarp
// A submission returns exactly one outcome with a typed payload.
record Task { title: string }
variant Submission {
    Accepted(record Task),
    Rejected(string),
}

pure funcra submit(title: string) -> variant Submission {
    if title == "" {
        return new Submission::Rejected("Enter a task title");
    }
    return new Submission::Accepted(new Task { title: title });
}

funcra present(outcome: variant Submission) -> unit {
    match on outcome {
        case Rejected(message) { print(message); }
        case Accepted(task) { print("Saved", task->title); }
    }
}

present(submit(""));
present(submit("Review settings"));
~~~

~~~text
Enter a task title
Saved Review settings
~~~

~~~sh
scarp verify examples/variant_validation.srp
scarp exec examples/variant_validation.srp
~~~

## Compatibility and limitations

These are experimental **interpreter** data-model features; they do not supply graphical windows, DOM, widgets or a general native executable compiler. Experimental native emitters cover narrower construct subsets. User-defined generics and the proposed host-side data engine remain outside this release. Exact Decimal and typed input from alpha.11 are retained.

[Historical alpha.11 Decimal release](/releases/v0.0.6-alpha.11).
