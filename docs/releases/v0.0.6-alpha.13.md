## Newly released behavior and limits

- **Option/Result:** early `?` propagation reuses an existing immutable `Err` payload; forwarding `None` performs no payload allocation. Normal postconditions and resource checks remain applicable.
- **Rust semantic caches:** `CompilationCache::set_limits` reconfigures retained-entry and logical source-byte limits. `evict_identity_revision`, `evict_identity_revisions_before`, `evict_identity_revisions_at_or_after` and `evict_identity_revisions_in_range` remove graph snapshots by trusted identity and caller-owned revision; the upper range bound is exclusive.
- **Rust editor analysis:** `EditorCompilationCache::analyze_loaded` binds the analysis to a host workspace generation. `EditorAnalysis::into_current` rejects stale outcomes even if individual source revision numbers match after import rebinding.
- **Unchanged:** no new Scarp syntax or CLI subcommands; `.srp` programs remain interpreted, without general native executable compilation.

### `examples/map_projection_snapshots.srp`

[Source](https://github.com/scarp-lang/scarp/blob/e755fda37cdaeed29434e848cb5dd41f2f2e7eb2/examples/map_projection_snapshots.srp) · [stdout](https://github.com/scarp-lang/scarp/blob/e755fda37cdaeed29434e848cb5dd41f2f2e7eb2/examples/map_projection_snapshots.stdout)

~~~scarp
// Canonical order and immutable snapshots after persistent map updates.
bind original = [map: 3: "three", 1: "one", 2: "two"];
bind keys = map_keys(original);
bind values = map_values(original);
bind updated = map_set(original, 2, "TWO");
bind reduced = map_remove(updated, 1);
print(keys);
print(values);
print(map_keys(reduced));
print(map_values(reduced));
print(map_len(original), map_len(reduced));
~~~

~~~text
[list: 1, 2, 3]
[list: "one", "two", "three"]
[list: 2, 3]
[list: "TWO", "three"]
3 2
~~~

### `examples/aggregate_resource_boundaries.srp`

[Source](https://github.com/scarp-lang/scarp/blob/e755fda37cdaeed29434e848cb5dd41f2f2e7eb2/examples/aggregate_resource_boundaries.srp) · [stdout](https://github.com/scarp-lang/scarp/blob/e755fda37cdaeed29434e848cb5dd41f2f2e7eb2/examples/aggregate_resource_boundaries.stdout)

~~~scarp
// Persistent map projections and deterministic boolean key order.
bind flags = [map: true: "enabled", false: "disabled"];
bind original_keys = map_keys(flags);
bind original_values = map_values(flags);
bind changed = map_set(flags, false, "off");
print(original_keys);
print(original_values);
print(map_values(changed));
print(map_len(flags), map_len(changed));
~~~

~~~text
[list: false, true]
[list: "disabled", "enabled"]
[list: "off", "enabled"]
2 2
~~~
