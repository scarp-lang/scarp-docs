## Published changes

- **CLI inspection:** `scarp inspect tokens`, `scarp inspect ast`, and legacy `scarp tokens` read regular UTF-8 files up to **1 MiB (1,048,576 bytes)**. Oversized sources fail before lexing.
- **String comparison:** `==` and `!=` for equal-length UTF-8 strings now charge a work step per started **64 bytes**, in both runtime and constant evaluation. Very tight limits may fail sooner.
- **Cache safety:** semantic cache reuse requires loader revisions to match host-supplied revisions; Rust callers must handle `RevisionMismatch`.
- **Checked ELF64 shifts:** restricted Rust-only object generation supports checked `<<`, `>>`, `>>>`. Counts outside **0–63** return status **3** (`CHECKED_KERNEL_INVALID_SHIFT`) and a UTF-8 operator span.

**Limit:** `scarp exec` still uses the interpreter. No general native compiler CLI is published; the ELF64 API is restricted to Rust hosts.

## Interpreter example

This demonstrates ordinary equality, not the precise work-budget boundary. Save this program as `hello.srp`.

~~~scarp
bind left = "नमस्ते";
bind right = "नमस्ते";
print(left == right);
print(left != right);
~~~

~~~text
true
false
~~~

~~~sh
scarp version
scarp verify hello.srp
scarp exec hello.srp
~~~
