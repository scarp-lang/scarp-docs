## Published changes

- `median(vector)` और `quantile(vector, fraction)`: pure statistics on finite vectors and visible windows, using type-7 interpolation and a bounded immutable sorted copy.
- Unicode: `text_lower`, `text_upper`, `text_reverse`, `text_from_codepoint`, `text_rfind`, `text_count`.
- Signed 64-bit: `bits_count_ones`, `bits_rotate_left`, `bits_reverse`, `integer_abs`, `integer_gcd`, `integer_lcm` and other checked utilities.
- Rust `ConstantCache`: live retention limits with oldest-first eviction; compiled programs remain usable.
- Restricted ELF64 Rust host API: page probes for large Linux x86-64 stack frames; both return ABIs preserved.

**Limit:** `scarp exec` uses the interpreter. No general native compiler CLI is shipped.

## Tagged statistics example

~~~scarp
// Median and type-7 quantiles use a bounded, immutable sorted copy.
bind samples = [4.0, 1.0, 7.0, 2.0];
print(median(samples));
print(quantile(samples, 0.25));
print(quantile(samples, 0.75));
bind visible = window(samples, 1, 3);
print(median(visible));
print(samples);
~~~

~~~text
3.0
1.75
4.75
2.0
[4.0, 1.0, 7.0, 2.0]
~~~

## Tagged text and integer example

This second example requires its [module dependency](https://github.com/scarp-lang/scarp/blob/244f713b4fa48f02a98b8e3e3c11025363f35260/examples/modules/collection_tools.srp) in the same directory structure.

~~~scarp
import "modules/collection_tools.srp" as collections;

bind labels = collections.labels();
print(labels[0], labels[1], labels[2]);
print(text_rfind(labels[2], "न"), text_count(labels[2], "न"));
print(integer_abs(-42), integer_sign(-42), integer_gcd(-42, 30), integer_lcm(-42, 30));
print(bits_count_ones(-1), bits_leading_zeros(1), bits_rotate_left(1, 63));
~~~

~~~text
STRASSE i̇ Aनवमन🌍
4 2
42 -1 6 210
64 63 -9223372036854775808
~~~
