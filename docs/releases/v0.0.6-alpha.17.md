## What's new

- Pure `array_len(values)` returns the length of an immutable fixed array.
- Pure `array_get_or(values, index, fallback)` returns a same-element-type fallback for invalid indices; **the fallback evaluates once even when the index is valid**. Normal `values[index]` retains its E0063 bounds failure.
- `input_boolean(prompt)` accepts exact lowercase `true` or `false` in interactive mode. Invalid input yields **E0084**; EOF before a line yields **E0055**.
- Improved diagnostics for invalid lengths nested inside fixed-array types, retaining focused source spans.
- Existing general native compilation limitations remain unchanged.

## Runnable fixed-array traversal

~~~scarp
bind readings = [array: 10, 20, 30];
var total = 0;
repeat array_len(readings) as index {
    total += readings[index];
}
print("Total:", total);
print("Missing reading:", array_get_or(readings, 3, 0));
print("Empty length:", array_len([array: <integer>]));
~~~

Expected output from the tagged example:

~~~text
Total: 60
Missing reading: 0
Empty length: 0
~~~



## Run the Boolean prompt with reproducible input

~~~sh
scarp exec --interactive --input-file examples/interactive/boolean_prompt.stdin examples/interactive/boolean_prompt.srp
~~~

~~~scarp
// Run with scarp exec --interactive examples/interactive/boolean_prompt.srp.
repeat 2 as attempt {
    bind confirmed: boolean = input_boolean("Continue (true/false)? ");
    if confirmed {
        print("Continuing");
    } else {
        print("Stopped");
        break;
    }
}
~~~

The input fixture contains exactly two lines:

~~~text
true
false
~~~

The tagged stdout snapshot includes prompts and results:

~~~text
Continue (true/false)? Continue (true/false)? Continuing
Stopped
~~~

They are not a guarantee that older Scarp compilers support these operations. Use `scarp version` before running them.
