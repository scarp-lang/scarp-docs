## Published changes

1. **One-command execution:** `scarp exec` without a file checks the current directory for a valid `scarp.project` or legacy `Scarp.project` manifest; otherwise uses `src/main.srp`, then `main.srp`. Invalid manifests are errors, not a reason to run another file. Explicit paths still work.
2. **Console input:** `exec` supports bounded interactive prompts and typed input as needed, without requiring an extra mode flag. `run` retains its opt-in behavior for interactive prompts.
3. **Persistent fixed arrays:** `array_set(values, index, replacement)` produces a new `array<T, N>` while preserving old aliases; an invalid index raises E0063, and successful copies charge the cumulative array budget (E0064). Indexed in-place assignment remains unavailable.
4. **Lifetime alpha.18:** empty finite and integer numeric windows detach from large backing allocations; nonempty views still share immutable storage. This is **not** general cycle collection or an RSS bound.
5. **Reliability:** interrupted prompt flushes are retried within the existing execution budget; JSON-inspection byte-exact regression coverage expanded.

## Command examples

~~~sh
scarp version
scarp exec
scarp exec calculator.srp
scarp exec src/calculator.srp
scarp verify src/main.srp
~~~

These commands work with the tagged **interpreter**. A source path is optional only for the published alpha.18 `exec` resolution rules; there is still no general `scarp compile` CLI. Source builds need Rust 1.74 or later.


## Runnable immutable array update

~~~scarp
pure funcra replace_last(values: array<integer, 3>) -> array<integer, 3> {
    return array_set(values, 2, 100);
}

bind original = [array: 4, 8, 12];
bind updated = array_set(original, 1, 99);
print(original[1], updated[1], array_len(updated));

bind nested = [array: [array: "one"], [array: "two"]];
bind localized = array_set(nested, 0, [array: "नमस्ते"]);
print(nested[0][0], localized[0][0]);
print(replace_last(updated)[2]);
~~~

Expected stdout from the tagged release:

~~~text
8 99 3
one नमस्ते
100
~~~


## Runnable numerical-window example

~~~scarp
// Lifetime preserves value snapshots without explicit memory management.
bind data = [1.0, 2.0, 3.0];
bind tail = window(data, 1, 2);
bind empty = window(data, 2, 0);
print(len(empty), tail);

bind numbers: integers = [integer: 7, 8, 9];
bind empty_numbers = ints_window(numbers, 2, 0);
print(ints_len(empty_numbers), ints_window(numbers, 1, 2));
~~~

Expected stdout from the tagged release:

~~~text
0 [2.0, 3.0]
0 [integer: 8, 9]
~~~
