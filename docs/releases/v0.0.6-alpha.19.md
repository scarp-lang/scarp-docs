# Scarp v0.0.6-alpha.19 — historical published prerelease

Published 23 November 2026. For current installations use [official downloads](https://scarp-lang.github.io/downloads/) and [current documentation](/guide/current).

This release introduced checked Rust callable handles, named argument mapping, defaults, signature- and effect-constrained slots, export-aware module selection and cumulative execution usage receipts. These are host embedding features, not first-class source function values.
