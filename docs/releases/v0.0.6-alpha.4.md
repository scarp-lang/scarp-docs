## Shipped features

- `sample_area(x, y)`: trapezoidal integration; `sample_cumulative_area(x, y)`: prefix integrals; `sample_slopes(x, y)`: consecutive interval slopes. Input vectors must be finite, equal-length and have strictly increasing coordinates.
- `cosine_similarity(left, right)`: finite similarity of equal-length, nonzero numerical vectors using independent scaling and compensated reductions.
- `scarp::native_object::emit_elf64_integer_kernel`: a **limited Rust-host API** emitting a relocatable x86-64 ELF64 object from one restricted integer initializer. **Not** a general native compiler, stable ABI or public `scarp compile` CLI.

The interpreter-backed CLI and source keywords are unchanged. Draft Top-P, Pearson correlation, GPU, tensors, general native executable generation, LSP and package management **are not shipped in alpha.4**.
