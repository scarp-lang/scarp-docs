## What this release adds

- **Deterministic nucleus selection:** `top_p(probabilities, mass)` returns selected original zero-based indices in descending probability order; `top_p_values(probabilities, mass)` returns the matching scores. This is ranking, **not random sampling**.
- **Centered scientific correlation:** `pearson_correlation(left, right)` returns the centered Pearson correlation of two equal-length, nonconstant finite vectors; unlike cosine similarity, it centers each input independently.
- **Limited native object API:** The Rust embedding function `scarp::native_object::emit_elf64_integer_kernel(source)` can now handle a bounded sequence of integer bindings that reference earlier bindings. It emits an **x86-64 ELF64 relocatable object**, not a standalone executable or general-purpose native compiler.

See [Top-P semantics](/language/nucleus-selection-alpha5) and [Pearson correlation](/language/pearson-correlation-alpha5) for edge cases, input validation and resource limits.

## Compatibility boundaries

The existing interpreter-backed CLI, typed diagnostics and bounded numerical behavior remain. **No `scarp compile` command**, general executable linker, GPU backend, tensor/autodiff engine, stochastic sampler, full LSP or package registry is included. Rust embedding users who match every `numeric::Builtin` variant may need to update their Rust code.
