[Official release](https://github.com/scarp-lang/scarp/releases/tag/v0.0.6-alpha.7) · [Immutable source commit](https://github.com/scarp-lang/scarp/tree/b1c1fd232b418267d95520c69ee563ac99ecae30)

## Two newly published language features

- **Typed conditional expressions:** `if`/`elif`/`else` now produce values. Conditions must be boolean, every branch has one result with the same exact static type, a final `else` is mandatory, and only the chosen branch is evaluated. [Full guide](/language/conditional-expressions-alpha7).
- **Unicode scalar escapes:** string literals accept `\u{HEX}` with one to six ASCII hexadecimal digits. Invalid escapes, surrogate codepoints and scalars above U+10FFFF report `E0003`. [Full guide](/language/unicode-escapes-alpha7).

**Limits:** Unselected branches are still statically typechecked. Conditional expressions are unsupported in module constants and the experimental C11/ELF64 backends. There is no BigInt, general `scarp compile`, interactive prompt API or stable ABI.

## Exact tagged source and output

The following complete example is copied byte-for-byte from the compiler tag's [`examples/conditional_unicode.srp`](https://github.com/scarp-lang/scarp/blob/b1c1fd232b418267d95520c69ee563ac99ecae30/examples/conditional_unicode.srp). [Expected stdout](https://github.com/scarp-lang/scarp/blob/b1c1fd232b418267d95520c69ee563ac99ecae30/examples/conditional_unicode.stdout):

~~~scarp
bind score = 73;
bind label = if score >= 90 {
    "\u{1F44B}"
} elif score >= 60 {
    "\u{0928}\u{092E}\u{0938}\u{094D}\u{0924}\u{0947} \u{1F44B}"
} else {
    text_repeat("unreached", -1)
};
print(label, if true { 7 } else { 1 / 0 });
~~~

~~~text
नमस्ते 👋 7
~~~

~~~sh
scarp exec examples/conditional_unicode.srp
~~~

The unselected `else` arm includes a runtime-failing operation. Its not executing demonstrates lazy branch selection, not a waiver of static typechecking.
