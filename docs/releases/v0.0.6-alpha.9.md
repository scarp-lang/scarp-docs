## What shipped

- **Exact signed BigInt arithmetic:** `bigint("12345678901234567890")` creates an explicitly parsed, exact decimal integer. The distinct `bigint` type supports arithmetic, comparison, functions, modules and tuples. The older `integer` remains signed 64-bit.
- **Structured project-test failures:** `scarp test --json=v2` returns schema-version-2 diagnostics, distinguishing `compile`, `fixture` and `runtime` phases. Existing `--json` continues to produce schema version 1.
- **Constrained resources:** BigInt defaults to 10,000 decimal digits and an 8 MiB cumulative limb budget. A ceiling of 1,000,000 digits can be requested only within other work and storage limits.

Continue with [BigInt language guide](/language/bigint-alpha9), [JSON-v2 test reports](/tooling/test-json-v2-alpha9) or the [alpha.8 project setup tutorial](/tutorials/calculator-alpha8). All examples here are pinned to alpha.9, not compiled from a moving main branch.

## Exact tagged compiler example

[Original source](https://github.com/scarp-lang/scarp/blob/0814997dc43982eb707a9a1aee72aab3a7ac8b41/examples/bigint_arithmetic.srp) and [expected stdout](https://github.com/scarp-lang/scarp/blob/0814997dc43982eb707a9a1aee72aab3a7ac8b41/examples/bigint_arithmetic.stdout) are copied byte-for-byte from the published compiler:

~~~scarp
// Development BigInt milestone; unavailable in published alpha.4.
bind a: bigint = bigint("999999999999999999999999999999");
bind one = bigint_from_integer(1);
print(a + one);
print(a * bigint("123456789"));
print(-a / bigint("1000000000000000000"));
print(-a % bigint("1000000000000000000"));
print(a > one, bigint_abs(-a) == a, bigint_to_integer(one));
~~~

~~~text
1000000000000000000000000000000
123456788999999999999999999999876543211
-999999999999
-999999999999999999
true true 1
~~~

From a checkout containing `examples/bigint_arithmetic.srp`, use the matching alpha.9 interpreter:

~~~sh
scarp verify examples/bigint_arithmetic.srp
scarp exec examples/bigint_arithmetic.srp
~~~

`verify` checks source statically; `exec` runs the program. Do not treat the expected output as a promise for modified code or future compiler releases.

## Compatibility boundaries

`integer` remains signed i64. BigInt conversion is explicit with `bigint_from_integer` and `bigint_to_integer`; overflow on conversion back to i64 is diagnosed. BigInt division truncates toward zero; the remainder has the dividend's sign. Implicit float/BigInt mixing, bitwise BigInt operations, fixed-size BigInt arrays and general `scarp compile` are **not shipped**. Rust embedders may need new `ExecutionOptions` fields and exhaustive type/diagnostic match arms. [Upstream BigInt technical contract](https://github.com/scarp-lang/scarp/blob/0814997dc43982eb707a9a1aee72aab3a7ac8b41/docs/bigint.md).

The [previous alpha.8 release](/releases/v0.0.6-alpha.8) introduced projects, `scarp test` and `assert`. Its example files remain release-pinned.
