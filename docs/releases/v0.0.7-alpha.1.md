## Changes

- `array_concat` joins fixed arrays with matching element types and infers the result length.
- `integer_gcd`, `integer_hcf` and `integer_lcm` accept two to 1024 integer arguments.
- Vector softplus uses a stable calculation for finite inputs.
- The interpreter reuses bounded frame buffers while preserving returned immutable values.
- Rust hosts may resize token-cache limits; insertion-order eviction preserves compiled snapshots.
- The experimental ELF64 API supports up to 16 required integer arguments, scalar conditional expressions, counted repeats and nested loop control.
- `scarp exec` interprets the current project with bounded input. New manifests use `scarp.project`; legacy `Scarp.project` remains readable.

See the [release guide](/guide/alpha7-first) for examples. General native calls, executable linking and a native compilation CLI are not included.
