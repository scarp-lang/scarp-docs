## Changes

- `scarp native-object` emits relocatable x86-64 ELF64 objects for a restricted pure-integer subset.
- `bounded-entry` selects a named entry and checks work and stack budgets across reachable nonrecursive same-file calls.
- Up to sixteen required integer arguments are supported: six in registers and the rest on the stack.
- The Rust API exposes checked aggregate layout metadata, not native aggregate execution.
- `scarp exec` remains interpreted. General linking, external calls, native recursion and heap-backed native values are unsupported.
