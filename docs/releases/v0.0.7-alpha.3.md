# Scarp v0.0.7-alpha.3 — published prerelease

Published 27 November 2026, 12:32:43 UTC. [Release](https://github.com/scarp-lang/scarp/releases/tag/v0.0.7-alpha.3) · [Source](https://github.com/scarp-lang/scarp/tree/44a3bb0a91e67570e46ce058a3f6211f8e5db0f5).

This page records evidence for the published compiler. Promotion of the documentation baseline requires separate validation.

## Changes

- Generic functions support bounded specialization, explicit type arguments and contextual inference.
- Generic Option and Result payloads support inference and pattern matching.
- Experimental ELF64 integer entries accept concrete integer specializations and private flat fixed-array, tuple and record stack locals.
- Checked constant folding preserves errors, source spans and work accounting.
- The interpreter supports string concatenation, repetition, raw and multiline literals.
- Lifetime retires unneeded interpreter values at function completion; this is not a process-wide RAM cap.

## Boundaries

`scarp exec` remains interpreted. Native output is experimental relocatable x86-64 ELF64 object code requiring an external linker. Native aggregate components are integer or Boolean; this is not general executable compilation, external calls, recursion or heap-backed native value support.
