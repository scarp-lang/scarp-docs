## Native compilation and stack frames

- Experimental x86-64 ELF64 `bounded-entry` supports bounded self and mutual recursion with separate work, active-frame and stack limits.
- Private native frames support nested fixed arrays, tuples and records containing up to 32 integer/Boolean leaves.
- Checked indexing preserves the failing source span. The public ABI remains integer arguments and a checked integer result.
- `scarp exec` still runs the interpreter. Native objects require an external linker; this is not general executable compilation.

[Nested aggregates and recursion tutorial](/guide/v007-alpha4-systems) · [Compiler native ELF64 contract](https://github.com/scarp-lang/scarp/blob/e620bdcb512fbe909b08f1b4cc625865e4cdf339/docs/native-elf64.md).

## BigInt and exact arithmetic

- Contextual return types can infer type arguments for inner generic calls.
- Bounded `bigint_pow_big` and `bigint_pow_mod_big` support wide exponents, subject to digit and work budgets.
- Experimental `scarp bigint` provides file-backed add, sub, bounded mul, div and div-wide operations, writing results to a new file.
- File division truncates quotients toward zero; the signed remainder follows the dividend.

[BigInt tutorial](/guide/v007-alpha4-bigint) · [Tagged compiler BigInt contract](https://github.com/scarp-lang/scarp/blob/e620bdcb512fbe909b08f1b4cc625865e4cdf339/docs/bigint.md).
